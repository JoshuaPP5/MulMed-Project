# Labyrinth of Baator

**Labyrinth of Baator** is a classic-style 2D role-playing game developed as a project for a Multimedia Systems course. It combines retro-inspired pixel art with modern turn-based tactical gameplay.

## 📖 Story Background
The world enjoyed peace until a mysterious dungeon, the **Labyrinth of Baator**, appeared ten years ago. Waves of monsters emerged, an event known as the "Great Waves," threatening all civilization. 

The protagonist, orphaned during these attacks, was raised and trained by a soldier. Now a hardened warrior, he enters the labyrinth with a single goal: revenge and the total destruction of the dungeon.

## 🎮 Gameplay Features
- **Movement:** Navigate the 2D grid-based world using **WASD** or **Arrow Keys**.
- **Action/Interaction:** Use the **Space Bar** to talk to NPCs, interact with objects, or trigger battles.
- **Sprint:** Hold **Shift** while walking to move faster.
- **Battle System:** - Strategic turn-based combat.
  - Command heroes using menus (Skills, Items, Attacks).
  - **Auto-Battle:** Toggle a feature where the system takes over controls.
  - **Escape:** Option to flee from unwanted encounters.
- **Menu System:** Press **Esc** to manage gear, use potions, check status, and invest skill points earned from leveling up to learn new abilities.
- **Questing:** Repeatable quests from NPCs like Julia at the Guild Shop to farm money and materials.

## 🖼️ Multimedia Usage
- **Visuals:** Highly detailed 2D pixel art with fluid battle animations and dynamic visual feedback (e.g., health bars changing color).
- **Audio:** Unique sound effects for actions (sword strikes, magic) and location-specific orchestral or ambient background music.
- **Narrative:** Story progression through text-based dialogues, cutscenes, and helpful on-screen tooltips.
